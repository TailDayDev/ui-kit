# Визуальная проверка — 21.10.2026

Что проверено: все 402 stories (76 компонентов, примитивы, токены) в web-Storybook (react-native-web), ширина 430pt, шрифты Inter подключены. Скриншот каждой story сравнивался с кодом исходного компонента в приложении (`frontend-mobile/src/shared/ui`) и с данными Figma.

Ограничения: это web-рендер. Нативные отличия (тени iOS/Android, нативные пикеры, анимации на native driver, safe area) проверяются только на устройстве — такие пункты помечены «проверить на устройстве». Figma MCP был на лимите, поэтому Figma сверялась по выгрузке от 21.10 (только для компонентов, которые в ней есть).

Обозначения: **(есть и в приложении)** — компонент перенесён 1:1, дефект унаследован.

## 3. Только web, но ломает Storybook

На телефоне так быть не должно, но, пока не поправлено, Storybook этим компонентам не верить. Исправляется кроссплатформенно без изменения вида на устройстве.

| Компонент                                              | Что видно                                     | Исправление                                                                                                |
| ------------------------------------------------------ | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| LabeledDetailRow (→ ContactDetailsCard, адрес)         | значение пропадает целиком                    | `flex: 0` + ширина → `flexGrow: 0, flexShrink: 0` (react-native-web превращает `flex: 0` в нулевую ширину) |
| OTPInput › Four Fixed Cells                            | ячейки схлопываются в линии                   | то же                                                                                                      |
| PercentageValueField, EditPercentageModal              | значение «25 %» не видно, «%» уехал за экран  | дать полю ввода `minWidth`/ширину (на web поле по умолчанию очень широкое)                                 |
| OfflineDataBar › Long Label                            | иконка сжимается до ~10pt                     | `flexShrink: 0` у обёртки иконки                                                                           |
| Input, Textarea, OTPInput › Focused                    | синяя рамка фокуса браузера поверх фиолетовой | `outlineStyle: 'none'` на web                                                                              |
| NativePicker, WheelPicker, DatePicker, SelectTimeModal | HTML `<select>` шрифтом Arial                 | ожидаемо, на устройстве колесо                                                                             |

## 5. Расхождения с Figma

Везде компонент совпадает с приложением, решение — за дизайном.

| Компонент               | Сейчас (приложение = библиотека)               | Figma                            |
| ----------------------- | ---------------------------------------------- | -------------------------------- |
| PetOwnerAvatar          | фото 56×56, инициалы Inter Bold                | 64×64, `body/regular`            |
| FieldRow                | без фона (просвечивает `#F9F9F7`), высота 52   | белый фон, 48                    |
| IconSquareButton        | 40×40 по умолчанию                             | 48×48, padding 12                |
| PullToRefreshErrorState | отступ 16                                      | 48                               |
| Textarea                | подпись `#333333`, высота ~78                  | `#828282`, 120                   |
| WheelPicker             | высота 220 (5×44), строки `headline/bold`      | 190, `title/regular`             |
| BaseSkeleton            | высота по умолчанию 22                         | 20                               |
| EmptyState              | кнопка — своя «таблетка» 44pt, padding 12/20   | Button: 51, padding-x 32         |
| ModalWithFooterActions  | кнопки по ширине текста (118 и 138)            | ряд 382×51, кнопки на всю ширину |
| ChipGroup (компактный)  | невыбранный счётчик на заливке `bg.accentSoft` | только акцентный цвет текста     |

**Решения дизайна 23.10.**

- Текст: межбуквенный интервал 0, высоты строк как в приложении (headline/medium — 20), strikethrough 14. Макет поправлен; в коде headline/medium уже 20, остальные записи `tokens/overrides.json` удалены после выгрузки токенов 23.10 (значения в коде не изменились).
- FieldRow: в макете без фона, 52 — совпадает.
- В коде, как в макете: PetOwnerAvatar (64 по умолчанию, инициалы обычным начертанием, лапа без фото), PullToRefreshErrorState (48 / 40), Textarea (подпись `text.secondary`, 120), BaseSkeleton (20), EmptyState (общий `Button`).
- Без изменений: IconSquareButton (40, на карточке задачи 48), WheelPicker (вид по коду), TodayTaskCard (как в макете).
- Ошибка сверки: ModalWithFooterActions и ChipGroup расхождений не имеют. В варианте `row` кнопки по ширине текста и разнесены по краям — 382×51 это ширина ряда, а не кнопок. У счётчика невыбранного фильтра заливка `bg.accent-soft` в макете есть.

## 6. Недочёты stories

Не влияют на компоненты, но мешают проверке.

- Рамка `FRAME` 430pt внутри холста 398/366pt: AdditionalNotes, CalendarModal, ConfirmationModal, Select, StickySegmentedControl, ScreenNav, модалки — правый край обрезан.
- StatusBadge › All Tones And Layouts: обёртки с `flex: 0` схлопывают бейджи друг на друга.
- StickyTabs › Inline: в meta-аргументах `position: absolute` для панели — список наезжает на табы.
- Состояния, которые не видны без нажатия: Pressable › Loading, ConfirmationModal › Loading/Action Failed, AdditionalNotes (модалка ни разу не открыта).
- PetOwnerAvatar › No Pet Photo и No Photos одинаковые (нет фото хозяина в аргументах).
- InfoRow использует RN `Switch`, а не `Toggle` из библиотеки.
- BaseSkeleton: stories называются `Components/Skeleton`.
- Tokens › Spacing: ключи 0.25/0.5/2.5 идут после 56; Radius And Shadows вылезает за холст.
- CalendarModal: даты зависят от сегодняшнего дня — скриншоты меняются каждый день.
- Картинки во многих stories — серые заглушки (ожидаемо: изображения передаёт приложение).
- 404 на `/favicon.ico` в первых stories — нет favicon в `preview-head.html`.
